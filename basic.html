HTML Lists

There are three types of HTML Lists

Unordered Lists

Unordered lists are lists that have bullet points to the left of each list item. These lists are contained in a <ul> tag. Each item in the list is contained in an <li> tag./

  • Cedric
  • Ian
  • Alex
  • Levi
  • Martin
  • Angus
  • Kaleb

NOTE: Unordered lists are the base HTML structure used to create navigation.

Ordered Lists

Ordered lists are used to create a sequence of items or steps. These list items have a number, roman numerals, or alpha character to the left of each item. Like <ul> items, ordered list items are contained in <li>

  1. Step 1: cracl eggs
  2. STep 2: add milk
  3. Step 3: whisk eggs and milk
  4. step 4: pour into a hot pan
  5. Step 5: stir until done

Absolute and Relative URLs.

URL: Universal Resource Locator - Otherwise known as a web address.

Absolute URLs: - This is a COMPLETE URL including the transfer protocol. Example:
https://resources.zybooks.com/WebProgramming/mediumCatv1.jpg

Relative URls - This specifies a "relative" path to the web resoource with no scheme or hostname (protocol or domain). They refer to resources based on the current web address you are in.

Section Links

A URL can point to a section or fragment of a document by adding a hashtag and a fragment identifier at the end of the URL.

Ex:
https://en.wikipedia.org/wiki/Computer_science#History

The section listed after the hashtag refers to an ID attribute. EX:
<sction id="History"> - what the id attribute creates is called a fragement identifier.
