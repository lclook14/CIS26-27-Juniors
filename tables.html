HTML Tables

The Table Element

<table> - This is the element that creates an HTML table. NOTE: HTML tables are used to organize data into rows and columns.

Cell

Cell - It is a location in the table at a specific row and column. cells are created at the intersection of a row and a column

Table Row

<tr> - an element that creates a row in a table. Table rows are nested inside of table elements.

Table Header

<th> - The element that creates a cell containing table header information about the data contained in a specific column or row.

Data Cell/Table data

<td> - An element that creates a table cell containing table data.

Caption

<caption> - This element defines a short descriptive text for the table.
