HTML Containers

Container

any element with an opening and closing tag that holds content.

<div>

Generic block container with no meaning of its own. This tag is usless without a class or id attribute.

<span>

Generic inline container with no meaning of its own. This tag is usless without a class or id attribute.

Block vs Inline

A block container (element) - starts on a new line and stretches across its parent containers full width. An inline container (element) - stays in the flow of the line and takes only as much room as its content.
